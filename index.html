PointAnimate - Point Cloud VFX Viewer & Editor

PointAnimate is a creative point cloud app for viewing, editing, and turning 3D scans into animated visual effects.

Viewer + Editor — Explore point clouds in 3D, crop and segment areas, remove noise and outliers, measure distances, and export your edits.

Animation + VFX — Choose from built-in animations, tune effect settings, save presets, and transform points into visual styles such as lines, contours, and vein-like structures. Create generative visuals for VJ workflows. Multiple presets available like Unknown Pleasures in 3D as in the video.

AR + Live Point Cloud — Experiment in AR with point clouds and slit-scan effect.

Coming soon: NDI output for sending PointAnimate visuals to TouchDesigner and other live visual tools.

Supported point cloud formats: PLY, E57, LAS, LAZ, PTS, XYZ, FBX and OBJ. Point position and color data are supported when available.
