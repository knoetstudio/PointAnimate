PointAnimate - 3D Point Cloud Viewer

Turn your scans into motion graphics with presets like particle dissolves, point-cloud morphing, and more visual effects. Create motion-graphics and VFX you’d normally make in Blender, right on your iPhone or iPad. Each point cloud loads XYZ coordinates. RGB color is supported when available. Supported 3D file formats: OBJ, PLY, LAZ, LAS, XYZ, FBX, STL, E57, GLB and USDZ
